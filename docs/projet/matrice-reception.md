# Exigences et périmètre reçu

Lecture au 20 novembre 2026. Le [cahier des charges](cahier-des-charges.md) et le [plan initial](plan-validation-initial.md) conservent les demandes d’origine. « Livré » signifie que le parcours décrit existe dans les sources et possède les preuves citées ; cela ne certifie pas toutes les machines ou tous les états possibles. « Partiel » conserve un reliquat explicite, même si sa phase est marquée implémentée. Les corrections postérieures aux campagnes sont consignées dans le [suivi courant](suivi-corrections.md).
