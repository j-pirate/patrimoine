# Correspondance entre conception et schéma livré

État du schéma SQLite **6**. Le [catalogue initial](modele-relationnel.md) conserve une intention de conception ; les six fichiers SQL ci-dessous décrivent la structure effectivement acceptée. Les commandes citées sont enregistrées dans [l’interface native](../../src-tauri/src/main.rs). Les règles qui portent sur plusieurs lignes sont aussi validées en Rust ; lire les `CHECK` SQL seuls ne suffit pas.

|---|---|---|---|
| Identités, changements, versions, audit | `objects`, `change_sets`, `revisions`, `audit_events` ; extensions du registre d’objets dans les migrations suivantes | [0001](../../crates/infrastructure/migrations/0001_foundation.sql) | ADR-003/009/013 |
| Référentiels et paramètres | `countries`, `currencies`, `app_settings`, `schema_migrations` ; catégories dans `asset_profiles.category`, sans table `asset_categories` | [0001](../../crates/infrastructure/migrations/0001_foundation.sql), [0002](../../crates/infrastructure/migrations/0002_registry.sql) | ADR-002/004 |
| Personnes, sociétés, tiers | `entities.kind` = `person` ou `company`, `entity_profiles` ; pas de sous-tables `people`/`companies` ni de nature `other_legal_entity` | [0002](../../crates/infrastructure/migrations/0002_registry.sql) | Mise en œuvre phase 3, ADR-003 |
| Famille et appartenance | Un espace familial par coffre, `family_memberships.person_id` ; pas de table `families` | [0002](../../crates/infrastructure/migrations/0002_registry.sql) | ADR-002/005 |

Les migrations 0001–0006 sont immuables. L’ouverture et la restauration contrôlent l’ancien schéma, migrent une copie puis activent une nouvelle génération. Les tests de [migration](../../crates/infrastructure/tests/registry_migrations.rs) comparent des schémas réels et conservent les sources. Cette page ne propose aucune modification de leur DDL.

Les identifiants ADR et les sections de mise en œuvre renvoient au [registre des décisions](decisions-architecture.md). Les dispositions initiales remplacées restent lisibles dans le catalogue, avec leurs limites locales et dans la [matrice de réception](../projet/matrice-reception.md).
