# Archives de validation

Rapports conservés pour la traçabilité des phases passées. Ils ne remplacent pas les vérifications les plus récentes.

Les renvois des rapports passent par l’[index des preuves](preuves.md) : chaque pièce y est identifiée dans l’archive versionnée, dans le dépôt ou comme conservée seulement dans l’environnement. Les originaux desktop des phases 2/3 ne sont pas dans le ZIP publié. La [matrice des campagnes](campagnes-validation.md) précise les programmes et sources connus, et les limites de chaque validation.
